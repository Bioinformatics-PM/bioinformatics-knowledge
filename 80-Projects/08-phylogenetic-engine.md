# 08-phylogenetic-engine

> [!abstract]
> From sequences to an interactive phylogenetic tree: alignment, distance matrix, tree construction.

## Objective

Build trees from aligned sequences with distance methods first (UPGMA, neighbor joining), then likelihood-based methods.

## Concepts required

- [[Phylogenetic Tree]]
- [[Distance Matrix]]
- [[UPGMA]]
- [[Neighbor Joining]]
- [[Maximum Likelihood Estimation]]
- [[Newick Format]]
- [[Tree (Data Structure)]]

## Four questions

| Lens | Answer |
|---|---|
| Biology: what is modeled? | Common descent and how sequences record it. |
| Mathematics: which model or algorithm? | Distances, tree metrics, likelihood. |
| Computer science: how is it implemented efficiently? | Tree data structures, clustering algorithms. |
| Product: how does it become a usable tool? | An interactive, clickable tree. |

## Scope

Uses 04-alignment-engine for the alignment step.
