# 10-genomic-pipeline

> [!abstract]
> A reproducible pipeline on real data: QC, alignment, variant calling, annotation, visualization.

## Objective

Process real sequencing data end to end with provenance, logging and reproducibility.

## Four questions

| Lens | Answer |
|---|---|
| Biology: what is modeled? | How sequencing data becomes biological knowledge. |
| Mathematics: which model or algorithm? | Error models, base quality, variant likelihoods. |
| Computer science: how is it implemented efficiently? | Workflow engines, containers, metadata and provenance. |
| Product: how does it become a usable tool? | A documented pipeline and its report. |

## Scope

Uses established tools where they are the standard; the point is the workflow.
