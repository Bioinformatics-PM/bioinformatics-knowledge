# NCBI E-utilities

> [!abstract]
> The Entrez Programming Utilities: NCBI's programming interface to PubMed and the other Entrez databases, a set of server-side programs called through plain URLs, documented in the "Entrez Programming Utilities Help" book on NCBI Bookshelf.

## Why this source

Every scripted search of PubMed, and every scripted download from GenBank or the other Entrez databases, ends as an E-utilities URL, whether written by hand or generated by a library such as `Bio.Entrez` ([[Biopython]]). The help book is the normative description of those URLs, written by NCBI.

## Coverage

Verified in this pass (chapter "A General Introduction to the E-utilities", NBK25497):

| Part | Content | Vault notes |
|---|---|---|
| Overview | Nine server-side programs giving a stable interface into the Entrez query and database system | [[Literature Search]], [[Biological Database]] |
| Base URL | All requests start with `https://eutils.ncbi.nlm.nih.gov/entrez/eutils/` | [[Literature Search]] |
| ESearch | Text query in, list of matching UIDs (and the query's term translation) out | [[Literature Search]] |
| EFetch | List of UIDs in, the corresponding records in a chosen format out | [[Literature Search]] |
| Usage policy | More than 3 requests per second from one IP address requires an `api_key` parameter | [[Literature Search]] |

The chapter "The E-utilities In-Depth: Parameters, Syntax and More" (NBK25499) documents every parameter; its content was not checked in detail in this pass.

## How to use it

- **L2**: read the general introduction once, then build an ESearch URL for a query you already ran in the PubMed web interface and compare.
- **L3**: script ESearch followed by EFetch, store the query string and the date with the results, and respect the rate limit.
- **M1**: build small literature or sequence datasets reproducibly; prefer `Bio.Entrez` once you have built the URLs by hand.

## Caveats

- Living documentation: `year` is the version consulted. Parameter names and limits can change; check the help pages before relying on a detail.
- NCBI hosts are not reachable from every environment (for example sandboxed containers); code that builds URLs can be tested offline, code that fetches them cannot.
