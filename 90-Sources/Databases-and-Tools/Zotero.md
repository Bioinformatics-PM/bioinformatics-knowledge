# Zotero

> [!abstract]
> A free, open-source reference manager for collecting, organizing, annotating, citing and sharing research sources, administered by the nonprofit Corporation for Digital Scholarship.

## Why this source

Zotero is the free, open-source example used in [[Reference Management]]: no license cost, a browser connector for capture, and export to the formats other tools read. Its documentation is the authority on what the tool itself does.

## Coverage

| Part | Content | Vault notes |
|---|---|---|
| Capture | Zotero Connector browser extension (Firefox, Chrome, Edge, Safari) saves references from web pages | [[Reference Management]] |
| Library | Items of many types (articles, books, web pages, datasets and more), organized and annotated | [[Reference Management]] |
| Citation | Citation Style Language (CSL) styles, over 10,000 available | [[Reference Management]], [[Scientific Writing]] |
| Exchange | Import and export of bibliographic data, including BibTeX for LaTeX users | [[Reference Management]] |

## How to use it

- **L1**: install Zotero and the Connector, save the papers you read for one concept note, and export their bibliography in one style.
- **L2**: export a collection to BibTeX and check that every record has a DOI.

## Caveats

- Tier C (tool documentation): cite it only for what Zotero does, never as the only support for a general claim.
- Verified in this pass through search results summarizing the Zotero site and university library guides: nonprofit administration, open source, Connector browsers, CSL and style count, BibTeX export. Feature lists change between versions.
