# Rosalind

> [!abstract]
> A free platform for learning bioinformatics through problem solving: programming problems of growing biological and computational difficulty, each answer checked automatically.

## Why this source

Rosalind matches the vault's method: learn a concept, then implement it. Problems can be solved in any language, the checker gives immediate feedback, and there are no prerequisites beyond patience. It was created by Phillip Compeau (UC San Diego, in Pavel Pevzner's group) and Nikolay Vyahhi (St. Petersburg), and it provides the exercises of the *Bioinformatics Algorithms* course, which makes it the companion of [[Bioinformatics Algorithms (Compeau)]]. The name honours Rosalind Franklin.

## How to use it

- **L1**: do Python Village if Python is new, then the first Stronghold problems in parallel with [[01-dna-engine]] and [[02-sequence-translation]].
- **L2**: solve the alignment problems while writing [[04-alignment-engine]]; try the Armory to learn the public tools.
- **L3**: solve the course problems chapter by chapter with the Compeau book; move each tested solution into [[bio-algorithms]] with its own unit tests.
- After each solved problem, link it from the matching concept note's exercises.

## Caveats

- The checker validates your answer, not the quality or complexity of your code: benchmark and test separately.
- Treat problem statements as exercises, not as a source for concept notes.
- Tier B, as set in the [[Conventions]] (recognized educators, problem-based tutorial).
- The exact problem list and launch year were not verified in this pass.
