# NCBI Bookshelf

> [!abstract]
> NCBI's free full-text collection of books and documents in the life sciences and health care, with the text linked to NCBI's molecular databases.

## Why this source

Bookshelf gives free, citable full text: textbooks, reference works and the documentation of NCBI's own resources. For this vault it is a place to read a chapter next to a concept note and to cite it at chapter level, which is why the [[Conventions]] list it as a tier A example.

## Coverage

Key publication: Hoeppner MA. "NCBI Bookshelf: books and documents in life sciences and health care". *Nucleic Acids Res* 41(Database issue):D1251-D1260 (2013). Bookshelf was created in 1999 with a single book used as an encyclopedic reference for resources such as PubMed and GenBank, and had grown to more than 1,300 titles at the time of the paper. Content is stored as XML in the NCBI Book DTD, modeled on the NLM journal article DTDs.

## How to use it

- **L1**: search Bookshelf for a topic you are studying and read one chapter alongside the matching concept note.
- **L2**: read the documentation of a database before using it seriously (for example the NCBI resource handbooks before a BLAST or E-utilities project).
- **L3 and M1**: use the chapter links as precise citations in concept notes: footnote the book's source note, then the chapter.
- Before citing, check whether the book already has a source note in `90-Sources/Books/`, and cite that note.

## Caveats

- Which textbooks, and which editions, are available was not verified in this pass. Check the edition shown on Bookshelf against the edition named in the vault's book note before citing.
