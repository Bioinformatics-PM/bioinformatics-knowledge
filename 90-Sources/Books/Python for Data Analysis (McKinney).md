# Python for Data Analysis (McKinney)

> [!abstract]
> A practical introduction to data manipulation in Python by the creator of pandas; the 3rd edition is open access as HTML.

## Why this source

The authoritative guide to the pandas, NumPy and IPython/Jupyter toolchain, written by pandas' creator and updated for pandas 2.0 and Python 3.10. It is the practical layer under almost every Python bioinformatics analysis.

## How to use it

- L1: Python, NumPy and pandas basics after the first programming course.
- L2: data wrangling and group operations, applied to Lab datasets.
- Code examples and datasets are on the author's GitHub repository (MIT-licensed code).

## Caveats

- A tool book, not a statistics book: pair with [[Introductory Statistics (OpenStax)]] or [[An Introduction to Statistical Learning (James)]].
- The online text may be read free but not copied or reproduced; print and DRM-free e-book versions are paid.
