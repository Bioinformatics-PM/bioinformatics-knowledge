# Modern Statistics for Modern Biology (Holmes)

> [!abstract]
> A statistics textbook for high-throughput biology, freely available online with runnable code and data, by a Stanford statistician and an EMBL computational biologist.

## Why this source

Written for exactly this curriculum's target: statistical thinking applied to modern biological data (sequencing counts, multivariate data, images), with every example reproducible. It grew out of the authors' Stanford course (Stats 366, Bios 221).

## How to use it

- L3: after an introductory statistics course and some programming; run the code alongside the text.
- M1: the high-throughput and design chapters for RNA-seq and multi-omics projects.
- Also mirrored at https://web.stanford.edu/class/bios221/book/

## Caveats

- Code is in R (not Python); translate examples if the Lab uses Python.
- The online version is licensed CC BY-NC-SA and is updated beyond the 2019 print edition.
