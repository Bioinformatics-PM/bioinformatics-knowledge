# An Introduction to Bioinformatics Algorithms (Jones)

> [!abstract]
> One of the first undergraduate bioinformatics textbooks, organized around the algorithmic ideas that drive the field.

## Why this source

It shows that a few algorithm design techniques solve many biological problems, and offers a dual table of contents, by algorithmic idea and by biological idea. Each problem gets a precise formulation and one or more solutions. Useful as a second angle on [[Bioinformatics Algorithms (Compeau)]].

## How to use it

- L2: read the chapter matching the current algorithm note to get the design-technique view.
- Prefer Compeau and Pevzner for a first reading; use this book for its problem formulations and biographical sketches of the field's pioneers.

## Caveats

- 2004: no coverage of next-generation sequencing methods (Burrows-Wheeler indexes, modern assemblers).
- Paid. Topic grouping follows the book's general scope, not a verified table of contents; verify chapter titles before citing chapters.
