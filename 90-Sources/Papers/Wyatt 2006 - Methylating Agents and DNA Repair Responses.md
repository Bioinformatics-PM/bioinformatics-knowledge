# Wyatt 2006 - Methylating Agents and DNA Repair Responses

> [!abstract]
> A review of how methylating agents damage DNA, which methylated bases they form, and which repair pathways remove each lesion or deal with the strand breaks that follow.

## Why this source

It connects the chemistry of alkylation (which atom of which base is methylated, and by which kind of agent) to the biology of repair and mutation, using the two classic laboratory methylating agents, methyl methanesulfonate (MMS) and N-methyl-N'-nitro-N-nitrosoguanidine (MNNG). It also corrects a common textbook shortcut about their mechanisms.
