# Barabási 2004 - Network Biology

> [!abstract]
> The review that introduced many biologists to graph theory: cellular networks (metabolic, protein interaction, regulatory) described with degrees, paths, hubs and modules.

## Why this source

A short, widely cited entry point to network biology, written for geneticists. It explains the graph vocabulary (degree, degree distribution, path length, clustering) on biological examples before discussing network architecture.

## Coverage

Citation: Barabási AL, Oltvai ZN. "Network biology: understanding the cell's functional organization". *Nature Reviews Genetics* 5(2):101-113 (2004). doi:10.1038/nrg1272.

- L2: read the network-measures part alongside [[Graph]] and [[Directed Graph]].
- L3: read the architecture part critically, with [[Random Graph]] null models and [[Degree Distribution]].

## Caveats

- 2004: interaction maps were young and incomplete; later work debated how well "scale-free" describes biological networks. Use the review for vocabulary and framing, not for current network statistics.
