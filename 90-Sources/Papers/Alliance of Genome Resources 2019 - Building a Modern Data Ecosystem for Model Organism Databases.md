# Alliance of Genome Resources 2019 - Building a Modern Data Ecosystem for Model Organism Databases

> [!abstract]
> The paper describing how six model organism databases and the Gene Ontology Consortium joined forces in 2016 as the Alliance of Genome Resources, to share data models, access methods and web pages across organisms.

## Why this source

Model organism knowledge is split across databases built by separate communities. This paper names the main ones, explains why their separation became a barrier to comparing data across species, and describes the shared infrastructure meant to remove it: the context a bioinformatician needs before mining gene function across organisms.

## How to use it

- L2: read the introduction for the list of model organism databases and what each curates.
- L3: compare a gene page on one member database with the corresponding page on the Alliance portal, and note which data were harmonized.

## Caveats

- Membership has changed since 2019; check the Alliance website for the current list.
- Plant and bacterial databases are not among the founding members.
