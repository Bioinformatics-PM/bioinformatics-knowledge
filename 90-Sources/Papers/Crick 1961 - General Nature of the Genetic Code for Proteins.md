# Crick 1961 - General Nature of the Genetic Code for Proteins

> [!abstract]
> The phage genetics experiment showing that the genetic code is read in groups of three bases, from a fixed starting point.

## Why this source

Using an acridine dye (proflavin) to add or remove single nucleotides in a bacteriophage gene, Crick, Brenner and colleagues found that one or two changes destroyed the gene's function, while three additions or three deletions together restored it. The only simple explanation is a code read three bases at a time from a fixed start: the reading frame. It is a model of pure genetic reasoning that reached a molecular conclusion before the code itself was deciphered.
