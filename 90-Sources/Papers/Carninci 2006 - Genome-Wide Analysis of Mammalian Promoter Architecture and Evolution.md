# Carninci 2006 - Genome-Wide Analysis of Mammalian Promoter Architecture and Evolution

> [!abstract]
> A genome-wide map of transcription start sites in mouse and human, built from tags for several hundred thousand start sites, which divides mammalian promoters into TATA-box promoters with a well-defined start site and broad, CpG-rich promoters.

## Why this source

Textbooks describe a promoter with a single +1; genome-wide start-site data show that many mammalian promoters start transcription over a range of positions, and that this shape correlates with sequence (TATA box or CpG richness), tissue specificity and evolution. It is the classic reference for promoter "shape" in start-site data.
