# MIT 7.01SC - Fundamentals of Biology

> [!abstract]
> MIT's OCW Scholar introduction to modern biology at the molecular level (biochemistry, molecular biology, genetics, recombinant DNA), built for independent study with videos, problem sets and exams with solutions.

## Why this source

- Designed for self-study (OCW Scholar): four units, one per topic, usable alone or together.
- Each unit bundles lecture videos, recitation videos, interactive concept quizzes, problem-solving help sessions, assignments with solutions and exams with solutions, plus a resource index.
- Molecular emphasis fits a bioinformatics path better than a broad organismal survey. It is the biology prerequisite named by [[MIT 6.047 - Computational Biology]].

Grouped by the four topics named in the course description.

## How to use it

- **Level L1**, first semester. No formal prerequisite (MIT students usually take it in their first year).
- Per session: lecture video, concept quiz, then the problem set before opening the solutions. Take each unit exam timed.
- Pair with [[MIT 5.111SC - Principles of Chemical Science]] for the chemistry underneath.
- Then [[MIT 7.03 - Genetics]] and [[MIT 5.07SC - Biological Chemistry I]] (L2). [[MIT 7.016 - Introductory Biology]] is a more recent alternative for the same core.

## Caveats

- Some resources are repurposed from earlier MIT introductory biology runs (the resource index includes 2004 lecture notes), so technology examples (sequencing, genome editing) are dated.
- Unit order and individual session titles were not checked one by one; the table follows the course description.
