# MIT 6.036 - Introduction to Machine Learning

> [!abstract]
> MIT's undergraduate machine learning course (Fall 2020): principles, algorithms and applications of machine learning from the point of view of modeling and prediction.

## Why this source

- Chosen over the older graduate 6.867 as the most recent and self-study-friendly MIT machine learning course on OCW.
- Delivered through MIT's Open Learning Library (free, enrollment optional): lectures, lecture notes, exercises, labs and homework.

## Coverage

| Part | Content | Vault notes |
|---|---|---|
| Foundations | Formulation of learning problems; representation, over-fitting, generalization | [[Statistical Learning\|Machine Learning]], [[Overfitting]] |
| Supervised learning | Classification and regression models | [[Supervised Learning]], [[Neural Network]] |
| Reinforcement learning | Learning from interaction | [[Statistical Learning\|Reinforcement Learning]] |
| Applications | Images and temporal sequences | [[Neural Network]] |

## How to use it

- **Level L3**. Recommended background: Python ([[MIT 6.100L - Introduction to CS and Programming Using Python]]), calculus ([[MIT 18.02SC - Multivariable Calculus]]) and linear algebra ([[MIT 18.06SC - Linear Algebra]]), plus a probability course.
- For omics, [[Stanford - Statistical Learning with Python]] is more statistical; take 6.036 for the computer-science view (optimization, neural networks), ideally after it.

## Caveats

- Interactive exercises and homework live on the Open Learning Library; the OCW page mostly points there.
- The lecture-level syllabus was not checked; rows follow the course description.
