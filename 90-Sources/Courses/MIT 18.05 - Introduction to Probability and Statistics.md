# MIT 18.05 - Introduction to Probability and Statistics

> [!abstract]
> MIT's elementary probability and statistics course (Spring 2022): combinatorics, random variables and distributions, then both Bayesian inference and frequentist testing, confidence intervals and linear regression, with R studios.

## Why this source

- Teaches Bayesian and frequentist statistics side by side at an introductory level, which is exactly the framing needed for bioinformatics.
- Materials: readings, class slides, problem sets with solutions, exams with solutions, studio activities in R. An interactive version (reading questions, problem checkers) is on MIT's Open Learning Library.
- Last run by Jeremy Orloff, who taught it many times.

## How to use it

- **Level L1 to L2**, the first probability and statistics course, after [[MIT 18.01SC - Single Variable Calculus]].
- Read before class, then do the problem sets; do the R studios even if you later work in Python.
- Deepen probability with [[MIT 6.041SC - Probabilistic Systems Analysis and Applied Probability]] or [[Harvard Stat 110 - Probability]], then statistics with [[MIT 18.650 - Statistics for Applications]].

## Caveats

- Class was taught in a reading-and-active-learning format: no lecture videos appear among the listed resources.
- Studios use R, not Python.
