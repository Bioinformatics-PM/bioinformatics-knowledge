# Stanford - Statistical Learning with Python

> [!abstract]
> Hastie and Tibshirani's Stanford Online course (on edX) on supervised learning, regression and classification, with Python labs, following *An Introduction to Statistical Learning*.

## Why this source

- Taught by two of the textbook's authors; clear, applied and short (11 weeks, 3 to 5 hours per week).
- Same chapter lectures as the R version, with lab lectures and computing in Python. The textbook (ISLR 2nd ed., and the Python edition ISLP) is free as a PDF on the book website.

## How to use it

- **Level L3**, after [[MIT 18.05 - Introduction to Probability and Statistics]], [[MIT 18.06SC - Linear Algebra]] and [[MIT 6.100L - Introduction to CS and Programming Using Python]].
- The most practical machine learning course for omics data; do every Python lab. Take it before [[MIT 6.036 - Introduction to Machine Learning]].
