# Coursera JHU - Genomic Data Science Specialization

> [!abstract]
> Johns Hopkins' Coursera specialization on understanding, analyzing and interpreting next-generation sequencing data, with Galaxy, Python, the command line, R and Bioconductor, ending in a capstone project.

## Why this source

- Covers the practical genomics stack end to end (technologies, tools, algorithms, statistics), designed and led by Johns Hopkins faculty.
- Intermediate level: the applied counterpart to the algorithm-first [[Coursera UCSD - Bioinformatics Specialization]].

## How to use it

- **Level L3**, after [[MIT 18.05 - Introduction to Probability and Statistics]], [[MIT 6.100L - Introduction to CS and Programming Using Python]] and courses I to III of the UCSD specialization.
- The Python and command-line courses can be taken earlier (L2), with [[MIT - The Missing Semester of Your CS Education]].
- Pair the Bioconductor and statistics courses with [[HarvardX PH525x - Data Analysis for the Life Sciences]].

## Caveats

- Per-course instructors (except the first course) and weekly syllabi were not checked. Launched around 2015: check tool versions against current documentation.
- Courses can be audited, but counting toward the specialization requires the fee-based track.
