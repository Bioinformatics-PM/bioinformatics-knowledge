# MIT 18.06SC - Linear Algebra

> [!abstract]
> Gilbert Strang's OCW Scholar linear algebra course (Fall 2011): matrix theory from Ax = b and the four subspaces to eigenvalues, positive definite matrices and the singular value decomposition.

## Why this source

- The reference introductory linear algebra course: complete lecture videos by Strang, a lecture summary per session, problem-solving videos by recitation instructors, problem sets with solutions, and exams.
- Emphasizes topics used in other disciplines, which is exactly the applied linear algebra that statistics and machine learning use.

## Coverage

| Unit | Content | Vault notes |
|---|---|---|
| I: Ax = b and the Four Subspaces | Systems of equations, elimination, vector spaces, the four fundamental subspaces | [[Matrix]], [[Gaussian Elimination]], [[Vector Space]], [[Linear Algebra]] |
| II: Least Squares, Determinants and Eigenvalues | Projections and least squares, determinants, eigenvalues and eigenvectors, diagonalization | [[Least Squares]], [[Determinant]], [[Eigenvalues and Eigenvectors]], [[Diagonalization]] |
| III: Positive Definite Matrices and Applications | Symmetric and positive definite matrices, similar matrices, linear transformations, SVD | [[Symmetric Matrix]], [[Positive Definite Matrix]], [[Linear Transformation]], [[Singular Value Decomposition]] |

## How to use it

- **Level L1 to L2**, in parallel with or right after [[MIT 18.01SC - Single Variable Calculus]].
- Priority for bioinformatics: least squares (regression), eigenvalues (Markov chains, PCA) and SVD.
- Prerequisite for [[MIT 18.065 - Matrix Methods in Data Analysis, Signal Processing, and Machine Learning]], [[MIT 6.036 - Introduction to Machine Learning]] and [[Stanford - Statistical Learning with Python]].
