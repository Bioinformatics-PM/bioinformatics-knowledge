# MIT 6.100L - Introduction to CS and Programming Using Python

> [!abstract]
> MIT's current full-semester introduction to computation and Python (Fall 2022, Ana Bell), from basic programming to algorithms, testing, debugging and complexity.

## Why this source

- Introduced with MIT's 2022 curriculum reform as the required introductory programming course (successor of 6.0001), with 26 lectures.
- Materials: lecture videos, lecture notes, problem sets, programming assignments with examples, readings, problem-solving notes, and podcasts.

## Coverage

| Part | Content | Vault notes |

| Computation and Python | Fundamental concepts of computation; the Python language | [[Python Programming\|Python (Programming Language)]], [[Python Programming\|Control Flow]] |

| Testing and debugging | Writing correct programs | [[Unit Testing\|Software Testing]], [[Programming\|Debugging]] |
| Complexity | Algorithmic complexity | [[Big O Notation]] |

## How to use it

- **Level L1**, first semester, no programming prerequisite. It includes all the content of the half-term 6.100A.
- Do every problem set in Python; this is the language used later in the Lab projects and in [[Coursera UCSD - Bioinformatics Specialization]].
- Next: [[MIT 6.042J - Mathematics for Computer Science]], then [[MIT 6.006 - Introduction to Algorithms]]. Pair early with [[MIT - The Missing Semester of Your CS Education]] for shell and git.

- The lecture-by-lecture list was not checked; rows follow the course description.
