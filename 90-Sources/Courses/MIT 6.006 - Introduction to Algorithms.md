# MIT 6.006 - Introduction to Algorithms

> [!abstract]
> MIT's core algorithms course (Spring 2020): modeling computational problems, classic data structures and algorithms, graph algorithms and dynamic programming, with the relationship between algorithms and programming in focus.

## Why this source

- Complete materials: lecture videos, lecture and recitation notes, problem sets with solutions, quizzes (exams) with solutions, and a week-by-week resource index.
- Its dynamic programming lectures (SRTBOT framework) are the most direct preparation for [[Sequence Alignment]].
- Named prerequisite of [[MIT 6.047 - Computational Biology]].

## Coverage

Lectures 4, 13 and 15 are verified by title; the rest is grouped from the course description.

| Part | Content | Vault notes |
|---|---|---|
| Models and data structures | Performance measures and analysis; data structures; Lecture 4: Hashing | [[Big O Notation]], [[Data Structures\|Data Structure]], [[Hash Table]], [[Sorting]] |
| Graph algorithms | Graph search and shortest paths; Lecture 13: Dijkstra's Algorithm | [[Graph]], [[Graph Traversal\|Breadth-First Search]], [[Graph Traversal\|Depth-First Search]], [[Shortest Path\|Dijkstra's Algorithm]] |
| Dynamic programming | Lecture 15: Dynamic Programming, Part 1 (SRTBOT, Fib, DAGs, Bowling) and following lectures | [[Dynamic Programming]], [[Recursion]] |

## How to use it

- **Level L2**, after [[MIT 6.100L - Introduction to CS and Programming Using Python]] and [[MIT 6.042J - Mathematics for Computer Science]].
- Do the problem sets; implement each data structure once in Python. Spend extra time on the dynamic programming block.
- Next: [[MIT 6.046J - Design and Analysis of Algorithms]] (L3) or [[Coursera Stanford - Algorithms Specialization]] as an alternative track.

## Caveats

- Lecture titles other than 4, 13 and 15 were not verified; the sorting and graph-search links reflect the course's announced scope.
