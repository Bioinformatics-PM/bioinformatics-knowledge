# MIT 18.065 - Matrix Methods in Data Analysis, Signal Processing, and Machine Learning

> [!abstract]
> Gilbert Strang's Spring 2018 sequel to 18.06: linear algebra for data analysis, signal processing and machine learning, from the SVD to stochastic gradient descent and neural networks.

## Why this source

- Connects matrix factorizations directly to data problems (dimensionality reduction, optimization, deep learning), which is the math behind most omics analysis.
- Lecture videos, problem sets, readings and instructor insights; graded on homework, labs and a final project (39 sessions).

## How to use it

- **Level L3**, after [[MIT 18.06SC - Linear Algebra]] (the stated prerequisite).
- Watch the SVD lectures before learning [[Principal Component Analysis]] for expression data; take the optimization lectures alongside [[MIT 6.036 - Introduction to Machine Learning]].

## Caveats

- The full lecture list was not checked; coverage beyond the two verified lectures is described only at the level of the course description.
- Signal-processing content is less relevant to this curriculum; skim it.
